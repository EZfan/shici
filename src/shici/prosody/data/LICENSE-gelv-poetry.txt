Vendored from gelv-poetry (https://github.com/chenmisss/gelv-poetry)
==============================================================================

This directory and the sibling ``_checker.py`` in ``shici/prosody/`` contain
code and data vendored from the upstream project ``gelv-poetry`` by chenmisss.

The vendored material is:

  - pingshui.json  - 平水韵 (Pingshui rhyme) character -> [[yunbu, tone]] map
  - xinyun.json    - 中华新韵 (14-rhyme Zhonghua Xinyun) map
  - charfreq.txt   - 6763 common Chinese characters ranked by usage frequency
  - SOURCE.md      - data provenance (transcribed from upstream)
  - _checker.py    - the original scripts/check.py validator (Python 3.8+)
