> 灵感来源:苏轼 *水调歌头* · 李白 *静夜思* · 李清照 *如梦令*
>
> `shici` 是一个面向终端的 AI 古典诗词生成器。它把大语言模型的文学创造力
> 与确定性格律校验引擎结合,生成严格遵守 **平水韵、平仄、词牌、对仗** 的古典诗词。

## ✨ 特性

| | |
|---|---|
| 🎯 **严格格律引擎** | 平水韵 106 部 + 平仄 16 式 + 词牌 20+ + 对仗评分。数据 vendored 自 [gelv-poetry](https://github.com/chenmisss/gelv-poetry) (MIT),离线可用 |
| 🤖 **LLM 创作 + 修订闭环** | 默认 DeepSeek-V3,Instructor 强制结构化输出。LLM 起草 → 格律校验 → 反馈违规位置 → LLM 修订,把单轮 60% 通过率提升到 **95%** |
| 📜 **20 个常用词牌** | 浣溪沙、如梦令、水调歌头、满江红、念奴娇、声声慢……每个词牌都有完整的律谱和代表作品 |
| 🔍 **RAG 全唐诗检索** | 可选 Chroma + `BAAI/bge-small-zh-v1.5`,47,809 行唐诗/宋词/诗经,语义搜索相似诗句、出处溯源、用典 |
| 🎨 **宣纸朱砂红 TUI** | `Textual` 多屏 TUI(首页/生成/校验/浏览),`Rich` 终端彩色输出,米黄 + 朱砂红的国风美学 |
| 🐍 **`uvx shici` 一行体验** | uv 全栈管理,PyPI Trusted Publishing 自动发布,3 OS × 3 Python CI 矩阵 |

## 🚀 30 秒上手

```bash
# 安装(推荐 uv)
uv tool install shici

# 校验一首诗(不需要 API key)
shici check examples/jueju-5.txt

# 查看任意字的平仄和韵部
shici lint "床前明月光"
shici rhyme 光

# 对仗评分
shici duilian "天增岁月人增寿" "春满乾坤福满门"

# 列出所有词牌
shici cipai

# 用 LLM 生成(需要 DEEPSEEK_API_KEY)
export DEEPSEEK_API_KEY=sk-...
shici generate --form 七言绝句 --theme 思乡

# 启动 TUI
shici tui
```

## 🏗️ 架构

```
              ┌──────────────────────────────┐
              │       LLM (DeepSeek-V3)      │  文学创造力
              └──────────────┬───────────────┘
                             │ 候选诗作 (Pydantic 结构)
                             ▼
              ┌──────────────────────────────┐
              │      格律校验引擎 (离线)     │  平水韵 + 平仄
              │  ┌─────────┬──────┬──────┐    │  + 词牌 + 对仗
              │  │classifier│ rhyme│cipai │    │
              │  └─────────┴──────┴──────┘    │
              └──────────────┬───────────────┘
                             │ issues / 评分
                             ▼
              ┌──────────────────────────────┐
              │  控制器: 接受 / 反馈修订      │
              └──────────────────────────────┘

  LLM 负责意蕴(主题、典故、意象),规则引擎兜底结构(平仄、押韵、对仗)
  两层解耦 → 文学性与格律性同时最大化
```

**核心算法**:`生成 → 校验 → 反馈 → 修订` 循环,2-3 轮即收敛。

```python
def generate_with_revision(theme, form, max_rounds=3):
    poem = llm.generate(theme=theme, form=form)
    for _ in range(max_rounds):
        result = prosody.check_poem(poem.lines)
        if result.ok:
            break
        poem = llm.revise(poem, feedback=result.issues)
    return poem
```

## 🔬 消融实验

评测集:200 个生成任务,覆盖 5 种体裁(五言绝句、七言绝句、五言律诗、七言律诗、浣溪沙)。
"通过率" = 当前修订轮次下被格律引擎接受的候选比例。

| 配置                              | 通过率   | 平均耗时 |
|----------------------------------|---------|----------|
| Baseline(单轮 LLM)              | 60 %    | 2.1 s    |
| **+ 修订循环** (核心)            | **92 %**| 6.5 s    |
| + 词牌 prompt 模板               | 95 %    | 7.2 s    |
| + RAG 注疏(全唐诗/宋词)         | 95 %    | 8.8 s    |
| + LLM-as-judge 评估              | 95 %    | 12.4 s   |

**最重要的发现**:**修订循环是最大的单一改进**,把通过率从 60% 拉到 92%。
词牌模板负责剩下的 3%。RAG 不提升通过率,但 LLM-as-judge 评估显示
**意象和用典质量提升约 35%**。LLM-as-judge 和 REST API 因成本 > 价值被简化。

详见 [docs/ablation.md](docs/ablation.md)。

## ❓ FAQ

**需要 API key 吗?**
不需要,`shici check` / `lint` / `rhyme` / `duilian` / `cipai` / `search` 全部离线。
`generate` / `critique` / `annotate` 需要 API key。

**支持哪些模型?**
任何 OpenAI 兼容端点:DeepSeek (默认,性价比最佳)、OpenAI GPT-4o-mini、
Qwen Plus、Claude Haiku、本地 Ollama 等。设置对应 `*_API_KEY` 环境变量。

**数据来源?**
平水韵字典来自 [gelv-poetry](https://github.com/chenmisss/gelv-poetry) (MIT)。
唐诗/宋词语料来自 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) (MIT)。
两者均 vendored 进 wheel,不联网即可使用。

**原创性?**
LLM 从主题、体裁、韵部开始独立生成。RAG 仅作软提示,不直接复制原句。
我们对 50 首诗的盲评显示 n-gram 重叠率 < 3%。

**商用?**
`shici` 本身是 MIT。但请遵守你所使用 LLM 服务商的服务条款。
